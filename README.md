# Address Book Management System - C Programming

A console-based Address Book project to manage contacts efficiently, developed using C programming.

### Features
- Add new contacts
- Search contacts by name
- Edit existing contacts
- Delete contacts
- List all contacts
- Save contacts to file
- Input validation

### Tech Stack
- Language: C
- Compiler: GCC
- Concepts: File Handling, Structures, Pointers

### How to Run
```bash
gcc projectadd.c -o addressbook
./addressbook
